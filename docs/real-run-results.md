# Проверка с настоящим Gemini

18 ноября 2026 года настроена модель `gemini-3.8-flash`. Обработано фотографий через Gemini — **0**.

Команда `npm run dev` завершилась до запуска HTTP-сервера. Среда выполнения вернула `listen EPERM` при открытии `127.0.0.1:43117`. В этой же среде не удалось разрешить имя `generativelanguage.googleapis.com`. До отправки изображения дело не дошло. Доступность модели по ключу, качество распознавания и время ответа остаются непроверенными.

В рабочей папке отсутствует каталог `test-photos`. Два встроенных изображения из `public/samples` — демонстрационные образцы. Результатов запросов для них также пока нет.
