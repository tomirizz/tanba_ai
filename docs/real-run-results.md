# Проверка Tańba AI с настоящим Gemini

18 ноября 2026 года опубликованная версия с моделью `gemini-3.1-flash-lite` вернула текст этикеток и переводы на казахский и русский. Проверена версия приложения из коммита `caedf5c`. [Сайт](https://tanba-ai.vercel.app/) · [Модель Google](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite)

## Загрузка изображений через API

Каждый файл отправлен на `POST /api/analyze` в поле формы `file`. Во всех успешных ответах получено `mode: "ai"`. Время измерено в браузере от отправки до получения JSON и округлено до десятых секунды. HTTP-коды сверены с журналом запросов Vercel.

| Файл | Язык по ответу | Прочитано из 11 | Пустые поля | Время, с | HTTP / ошибка |
| --- | --- | --- | --- | ---: | --- |
| `oat-cookies.png`, образец проекта | Английский | 8 — название, состав, количество, дата изготовления, срок годности, хранение, изготовитель, пищевая ценность | Импортёр, рекомендации, ГМО | 8,8 | 200 |
| `hazelnut-chocolate.png`, образец проекта | Турецкий | 6 — название, состав, количество, срок годности, хранение, изготовитель | Дата изготовления, импортёр, пищевая ценность, рекомендации, ГМО | 20,9 | 200 |
| `Ingredients list.jpg`, внешний фрагмент этикетки, первая попытка | — | Нет ответа | Нет данных | 46,0 | 502 / `aiFailed`, истёк срок ожидания |
| Тот же внешний файл, повторная загрузка | Английский | 1 — состав | Название, количество, дата изготовления, срок годности, хранение, изготовитель, импортёр, пищевая ценность, рекомендации, ГМО | 6,1 | 200 |
| `no-label-control.png`, однотонное изображение без этикетки | — | Нет результата | Нет данных | 4,0 | 422 / `noLabel` |
| `oat-control-blur.png`, текст образца сделан нечитаемым уменьшением до 22 пикселей по длинной стороне и увеличением | — | Нет результата | Нет данных | 21,3 | 422 / `noLabel` |

Поле считалось прочитанным, если в ответе был текст оригинала. Для каждого такого поля пришли оба перевода. Во всех трёх успешных ответах `eacMark` имел значение `false`. Знак EAC учитывается отдельно. **Качество перевода — проверить человеку.**

Внешний файл содержит только список ингредиентов. В первом запросе журнал функции зафиксировал `AbortError`. Во втором ответ начался словами «INGREDIENTS: Corn, sugar, peanuts (6%), honey (2.5%)». ## Предыдущие попытки

До публикации версии `caedf5c` тот же английский образец отправлялся в режиме обычной загрузки. Во всех четырёх случаях Google ответил `503 UNAVAILABLE` из-за высокой нагрузки, а приложение вернуло HTTP 502 и `aiFailed`. Полей для проверки в этих ответах нет.

| Модель | Время попыток, с |
| --- | --- |
| `gemini-3.8-flash` | 12,1 и 6,9 |
| `gemini-3.5-flash-lite` | 11,3 |
| `gemini-3.1-flash-lite` | 4,0 |

В версии `caedf5c` после ответа Google 503 предусмотрен один повтор с той же моделью через Interactions API и параметром `store: false`. На обе попытки отведено 45 секунд. Сами успешные JSON-ответы не показывают, понадобился ли серверу автоматический повтор.

## Сайт и интерфейс

| Действие | Результат |
| --- | --- |
| Открыть главную | HTTP 200, видна кнопка выбора фото |

| Открыть каждый из двух встроенных примеров | Оба открыли редактор с пометкой демо. Изменённое русское название английского примера появилось в макете для экспорта |

## Фотографии команды

В рабочей папке не было каталога `../test-photos`. Два изображения из проекта, внешний фрагмент этикетки и два контрольных изображения перечислены выше отдельно. Результаты на исходных фотографиях команды, включая снимок без этикетки и размытый снимок — [TO FILL].

Локальный сервер не смог открыть порт (`listen EPERM`) и завершился. Все результаты HTTP в этом отчёте получены на опубликованном сайте.

## Проверка товарных этикеток после расширения MVP

В рабочей версии через обычную кнопку загрузили два контрольных изображения, созданных для проверки и отсутствующих в каталоге демо. В корейской сыворотке Gemini прочитал предупреждение и номер партии `KM-732`. Номер сохранился в двуязычной наклейке для экспорта. На этикетке сумки в первом варианте потерялись модель и габариты. После выделения отдельных полей повторная загрузка вернула `TOTE-418`, `36 x 42 см` и `100% хлопок`. Между попытками Google также вернул 503 при высокой нагрузке. На турецкой пищевой этикетке открылся пищевой чек-лист. Переводы — проверить человеку.
